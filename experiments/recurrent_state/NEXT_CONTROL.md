# 从全局h到分槽状态：预先规定下一对照

当前GRU基线96维状态在8实体随机覆盖下不可靠；不能据此判断所有内部状态方案不可行。

下一对照固定任务流、训练步数/序列长度，先比较：

- Global：现96维全局h；
- Learned slots：8×12维状态、query-conditioned read，更新门由输入学习；
- Oracle-addressed slots：使用显式entity ID更新对应slot，作为强接口辅助基线，不当作模型学会寻址。

持久激活同为96floats，但参数、计算、寻址辅助不同，必须分别报告，不宣称全资源匹配。不得用entity ID当神经泛化证据。

评价：训练长度/4倍/16倍流、距最后写入年龄、未写入query拒答、同entity纠正、改变实体更新频率、重置状态、未见映射组合。先固定目标和预算，不按test阈值选优。

历史fallback后续单独增加：普通最新值字典可作外部oracle reference，但调用次数/保存信息必须记账；用固定独立验证集选触发policy，在test检查错误自信与覆盖，不能只报告fallback后总准确率。
